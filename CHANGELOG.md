# Changelog

All notable changes to Knowledge-Agent will be documented here. The format is
based on Keep a Changelog and the project follows Semantic Versioning after
the first stable release.

## [Unreleased]

### Added

- Open-source repository structure, governance and security documentation.
- Unified web console with OIDC login and per-user conversation isolation.
- Verified-email self-registration configuration for Keycloak.

## [0.1.0] - 2026-07-21

### Added

- Durable MinIO/MongoDB document ingestion with leased workers.
- BGE-M3 dense/sparse embeddings and Milvus hybrid retrieval.
- Citation-aware streamed chat and persistent conversation history.
- Redis Streams event replay, Prometheus metrics and schema administration.
- Docker Compose deployment profiles and automated quality gates.
